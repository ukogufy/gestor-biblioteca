# Gestor de Biblioteca

Prototipo académico: usuarios, libros, préstamos y reservas.
Stack: NOde.js + Express, React 18 + Vite, PostgreSQL y/o MongoDB.
Flujo Git: main, devolop, feature/*.

## Estructura
- backend/
- frontend/
- docs/unl/
- db/
- scripts/

## Requisitos
- Node LTS (nvm)
- PostgreSQL 14+
- MongoDB 7+
- VS Code

## Ejecución rápida (a completar en semanas siguientes)
- Backend: 'cd backend && npm install && npm run dev'
- Frontend: 'cd fronted && npm install && npm run dev'
